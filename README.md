# WMS tester

A minimal client to test a web map service

Sometimes you just want to check if a WMS service is running and provides useful output.
Navigate to the [github.io](https://pvgenuchten.github.io/wms-tester/) and run your test.
Or run locally by cloning `index.html`, run `npx httpserver` in the folder and point your browser to <http://localhost:8080>.

Mind that your WMS service should have [CORS](https://www.geeksforgeeks.org/javascript/how-to-handle-cors-in-javascript/) enabled.
